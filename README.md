# Favorite Teams Schedule

A GitHub Pages dashboard for 17 Seattle, University of Washington and U.S. national teams. The default view shows the next seven calendar days in Pacific time. Use the team and date range filters to see up to 30 days.

## Publish

Commit these files to the repository's default branch. In GitHub, open **Settings → Pages** and choose **GitHub Actions** as the source. Then open **Actions → Publish game schedule → Run workflow** for the first deployment. Subsequent refreshes run every Monday at 14:23 UTC, and on default-branch changes to the site or refresh code. GitHub may delay scheduled jobs. The deployment link appears on the workflow run.

## Edit and preview

Team configuration lives in `site/teams.json`. From the project root, run:

```sh
python -m pip install -r requirements.txt
python refresh.py
python -m http.server 8000 --directory site
```

Open http://localhost:8000. Use `python refresh.py --demo` for a network-free UI preview. Demo rows are labeled and are never generated by the publishing workflow.

## Schedule data

The refresh job reads ESPN team schedules for the professional teams and the USA national teams, University of Washington athletics calendars for the Huskies, and the official Seattle Torrent schedule. The site links to the upstream schedules. Competition coverage depends on the upstream team schedules, especially for national-team windows, playoffs and tournaments. Unannounced start times and locations may appear as TBD. If an individual source fails, the page identifies that team. If all sources fail, the workflow stops before publishing so the previous page stays available.
